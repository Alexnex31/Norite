# CLI `--json` output schemas

Versioned JSON Schema files for every CLI command's `--json` output, one file per command (see
`docs/architecture.md` §4 and §10, and `CLAUDE.md` rule 15). Empty until Milestone M46 — a schema change
ships in the same commit as the code change that causes it, the same rule as `openapi.yaml` and
`gateway-events.schema.json`.
