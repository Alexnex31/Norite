# Dependency licenses read by hand, because go-licenses cannot classify them.
#
# Each of these modules ships a LICENSE file holding only the Apache-2.0 notice ("Licensed under the Apache
# License, Version 2.0 ...") and not the license's text, which is what the classifier matches on, so it
# reports them Unknown and `check` fails. They arrived at M24 through sigstore-go. Each file was read, and
# its SHA-256 is recorded: scripts/license-overrides.sh refuses a module whose LICENSE no longer has that
# hash, so a version that changes its terms is read again rather than waved through.
#
# This is the only way a dependency gets past the classifier, and it is for that one case. A module with
# no license file, or one whose terms are not on ADR 0032's list, does not belong here.
#
